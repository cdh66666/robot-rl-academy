浏览器里是 MuJoCo 物理仿真与 DQN 的入门实验；你自己的机器人还需要建立模型、训练并在具体硬件上逐项验证。仿真结果不会自动变成真机结果。

开始前你可能想知道

零基础可以学吗？

可以从第 1 课按顺序开始。每课先说明要理解什么、为什么学，以及完成后的具体结果；不需要先会写强化学习代码。

需要安装软件或购买显卡吗？

两个网页实验在浏览器中运行，不需要账号或 GPU；首次打开需联网加载网站和物理引擎文件。进阶 Python 工程需要安装依赖，也可下载云端笔记本使用支持 Python 的环境。

能直接上传自己的机器人开始训练吗？

本网站的浏览器训练器目前是固定的倒立摆教学环境，不支持上传任意机器人模型。课程提供单关节仿真工程、接口表和迁移步骤，实际机器人需要依据其模型、驱动与传感器适配并重新验证。

先确认这四件事

  1. 观察一致仿真里的输入，真机能否按相同顺序、单位和频率拿到？
  2. 动作一致网络输出是目标位置、速度还是力矩？底层控制器如何执行？
  3. 参数有依据质量、摩擦、延迟和限幅先测量或记录范围，不凭空填写。
  4. 保护独立超时、急停、限位和失联处理由策略之外的层执行。
