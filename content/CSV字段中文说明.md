# 接口契约表和辨识记录：字段怎么填

两张 CSV 是空模板，不包含任何设备实测值。可以用表格软件打开，或者把模板和设备手册交给 AI 协助整理。每个值都应注明来源；不支持、未测或未知的字段留空，并在备注中说明，不要当作零。

## 一、接口契约模板

每行描述一个策略输入或输出；`index` 表示送入模型时的固定顺序。输入与输出分开填，并保留同一个版本号。

| 字段 | 中文含义 | 填写要点 |
| --- | --- | --- |
| type | 类型 | 输入可写 observation，输出可写 action |
| index | 顺序编号 | 按实际数组从 0 开始；换主控时不随意调整 |
| name | 量的名称 | 如关节角、目标角、位置参考 |
| source_or_joint | 来源或关节 | 对应传感器或执行关节；以实际硬件为准 |
| unit | 单位 | 如 rad、rad/s、N·m；不要只写“位置” |
| coordinate_and_sign | 坐标系与正方向 | 写清轴、方向和坐标约定 |
| zero | 零点 | 写清零位定义和是否已校准 |
| normalization | 归一化 | 写出偏移、缩放、裁剪，未使用则注明 |
| valid_min、valid_max | 有效范围 | 写明范围来源，区分传感器范围与机械限制 |
| update_period_ms | 更新周期 | 毫秒；策略、驱动和传感器可能不同 |
| timeout_ms | 超时阈值 | 由具体设备和安全设计确定，不使用课程虚构数值 |
| mode_or_failure_action | 控制模式或故障动作 | 写位置/速度/力矩模式，及故障时设计的安全状态 |
| measured_status | 数据状态 | 标明实测、厂家资料、估计或待测 |
| notes | 备注 | 记录版本、假设和未解决事项 |

## 二、辨识记录模板

每行代表一个采样时刻。命令时间和反馈时间要分别记录；若不同设备时钟未同步，应先说明并处理。

| 字段 | 中文含义 | 填写要点 |
| --- | --- | --- |
| session_id | 测试批次 | 对应一组已记录工况的试验 |
| sample_time_monotonic_ms | 采样单调时间 | 使用同一单调时钟；单位毫秒 |
| command_time_ms、feedback_time_ms | 指令和反馈时间 | 不要把发送时间当作反馈实际发生时间 |
| joint_name、device_id、mode | 关节、设备标识和模式 | 对应设备型号与控制模式 |
| command_value、command_unit | 指令值和单位 | 例如目标位置 rad；不得冒充反馈值 |
| position_raw | 原始位置读数 | 保留原值以便复查零点、方向和尺度 |
| position_rad、velocity_rad_s | 换算后位置与速度 | 分别为 rad 和 rad/s；注明换算依据 |
| measured_current_A | 实测电流 | 仅当设备支持且含义明确时记录；不能直接等同输出轴力矩 |
| bus_voltage_V、temperature_C | 电压和温度 | 仅记录实际可读值 |
| feedback_age_ms | 反馈数据年龄 | 需要有可信的时间戳或测量方法 |
| device_error、limit_flag | 错误和限位状态 | 使用设备手册中的实际定义 |
| note | 备注 | 记录负载、安装、异常、缺失值及测量方式 |

详细采集条件、拟合/留出验证和安全阶段见[真实机器人实战工作手册](真实机器人实战工作手册.md)。
