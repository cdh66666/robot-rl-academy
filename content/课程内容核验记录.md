`lessons.json` 包含 10 课；每课都有学习目标、目的、预期成果、正文、具体练习、带答案的自测和参考来源。视频分镜 01、02、04–06、08、09 各 8 场，03 和 07 各 10 场，10 为 17 场。播放时长由实际渲染决定；页面显示的是学习时间估计，安装、训练及实测按课另外说明。

## PPO 仿真项目核对

`project/README.md` 及发布包提供 Python 虚拟环境、依赖、训练、观察和 ONNX 导出说明；课程要求按 README 使用虚拟环境的 Python，而不是假设已经全局安装依赖。PPO 项目使用 Gymnasium `InvertedPendulum-v5`，观察顺序为 `[小车位置, 杆角度, 小车速度, 杆角速度]`，与浏览器 DQN 不同；动作是连续推力，也不是相同的模型或评分条件，第 10 课已提醒不能互换策略或直接比较分数。

制作时一次实际运行的原始记录位于 `project/sample/evaluation.json` 和 `project/sample/policy.verification.json`：请求 60000 步、实际 61440 步；20 回合随机平均 6.4 步，训练策略 20/20 到 1000 步截断；ONNX 对照 101 输入最大绝对误差 `7.152557373046875e-07`。图文和口播明确这是单次仿真样本，不保证其他条件复现，不是实体机器人结果。

额外单关节项目已位于 `project/joint/`，第 10 课按其 README 与 `contract.py` 区分 ONNX 图内的动作夹紧、图外的位置映射和参考变化率限制。`project/joint/artifacts/evaluation.json` 记录同一简化模型下 20 个训练外初始条件：PPO 末尾 50 步平均误差 0.009069 rad、直接目标基线 0.028634 rad，均 20/20 满足项目判据且无提前终止；`stress_slew/evaluation.json` 记录另 100 个初始条件。仅为仿真评估，不表示真实硬件或其他工况表现。首次跟练使用独立的 `first_check` 输出目录，避免覆盖随包记录。

## 系统辨识离线跟练

`identification_demo/identify_demo.py` 已实际运行，输出明确标记为合成的 CSV、拟合报告与曲线 SVG；曲线也已在浏览器渲染为 PNG 并目视检查。该次输出的留出验证 RMSE 为 0.002740 rad。附加检查把**留出验证段**的位置数据全部替换为明显异常值，保持拟合段不变；拟合得到的两个参数不变，验证了参数选择未读取留出段位置。原始验证采用验证段首个测量值初始化开环预测，这一点明确写在 README 和报告中。

根任务随后提供了 `identification_demo/browser.html`，并实际在浏览器运行“开始拟合与验证”；对同一 1001 条合成样本得到 0.240 s、0.160 s 和 0.002740 rad，与 Python 记录一致。第 07 课已把网页操作放在首选步骤，Python 离线练习作为进阶。

该例是已知一阶模型生成的数据，模型形式与候选网格刻意吻合；不能由此推断真实电机性能。拟合有效延迟可能综合采样、滤波、通信、驱动器和执行器响应，不能等同纯通信延迟。真实硬件采集需要现场安全条件，未提供的数据留空并标记未测。
