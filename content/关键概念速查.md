# 机器人强化学习：关键概念速查

这张表不是让你先背完术语。遇到陌生词时回来查，再到相应课程和实验里看它实际做了什么。

## 一、训练闭环

| 词 | 一句话理解 | 在课程倒立摆中 |
| --- | --- | --- |
| 环境 | 接收动作并返回结果的任务接口 | 模型、重置、一步推进、奖励和结束规则 |
| 状态 | 世界当前与未来有关的真实情况 | 小车和杆的位置、速度等 |
| 观察 | 策略实际拿到的数据 | 小车位置、速度、杆角度、角速度；顺序固定 |
| 动作 | 策略能发出的选择 | 向左或向右施加推力 |
| 奖励 | 训练时衡量每一步结果的信号 | 每步基础 +1，物理失败默认额外 −5 |
| 策略 | 根据观察决定动作的规则 | 评估时选评分较高的方向；训练探索期间也会随机尝试 |
| 回合 | 从重置开始，到失败或时间上限的一段过程 | 最多 500 次决策；一次失败也会结束 |
| 终止 / 截断 | 任务本身结束 / 到达外部时间限制 | 倒下是终止；到 500 步是截断 |

## 二、网络怎样学

| 词 | 要抓住的意思 |
| --- | --- |
| 神经网络 | 带可调整参数的函数：把输入数字变成输出数字。 |
| Q 值 | 对某个观察与动作的未来折扣累计奖励的估计；不是电机电流。 |
| DQN | 用神经网络估计各个离散动作的 Q 值，再按经验更新。 |
| 探索 | 训练时尝试当前未必最优的动作，收集新经验。 |
| 经验回放 | 保存过去的交互样本，随机抽一批用于学习。 |
| 目标网络 | 一份较慢更新的网络副本，帮助减少学习目标的波动。 |
| Double DQN | 在线网络选择下一动作，目标网络评价该动作。 |
| PPO | 用当前策略收集轨迹，更新策略与价值估计；可用于连续动作，也可用于离散动作。 |
| actor / critic | actor 给动作分布，critic 估计未来回报；优势用于判断动作比预期好还是差。 |
| 裁剪目标 | PPO 减少策略更新过大时继续获益的动力；它不是硬件安全限幅。 |

## 三、从仿真走向机器人

| 词 | 要抓住的意思 |
| --- | --- |
| MuJoCo | 根据模型、作用力和约束计算物理变化的仿真引擎；它不自动等于训练算法。 |
| MJCF | 描述 MuJoCo 模型的 XML 格式；模型文件之外还需要任务环境和训练器。 |
| 控制周期 | 策略多久输出一次动作。本网页实验是 20 ms，但不代表适用于所有机器人。 |
| 位置 / 速度 / 力矩模式 | 三种不同的指令含义；内部闭环和支持情况要查具体驱动器手册。 |
| 系统辨识 | 用命令和反馈数据估计可解释的模型，并用留出数据检验。 |
| 域随机化 | 在训练中改变合理范围内的参数，让策略面对更多情况；测试时改参数不等于训练随机化。 |
| 接口契约 | 明确输入输出的顺序、单位、坐标、归一化、范围、时序与失效处理。 |
| 影子运行 | 使用真实传感输入计算并记录策略输出，但不向电机发送运动指令。 |
| ONNX | 模型交换格式之一；模型文件不自动包含驱动、动作后处理或独立安全保护。 |

浏览器 DQN 的输入顺序是 `[位置, 速度, 角度, 角速度]`；Python PPO 倒立摆示例是 `[位置, 角度, 速度, 角速度]`。两者的动作和模型也不同，不能因为输入都是四个数就互换策略。
